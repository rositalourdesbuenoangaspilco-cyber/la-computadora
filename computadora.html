Bienvenido a Aprende Computación. Aquí conocerás las partes de una computadora y aprenderás sobre hardware y software.

¿Qué es una computadora?

Es una máquina electrónica que recibe, procesa y almacena información.

🖥️ ¿Qué es el Hardware?

El hardware son todas las partes físicas de una computadora que podemos tocar.

1. Monitor

Es la pantalla donde podemos ver imágenes, videos, textos y programas.

2. Teclado

Sirve para escribir letras, números y dar órdenes a la computadora.

3. Mouse

Permite mover el cursor, seleccionar y abrir programas.

4. Gabinete o torre

Es la caja que contiene componentes importantes como la placa madre, el procesador y la memoria RAM.

5. Procesador

Es el componente que ejecuta instrucciones y procesa información.

6. Memoria RAM

Almacena temporalmente los datos que se utilizan mientras trabajamos.

💿 ¿Qué es el Software?

El software es el conjunto de programas e instrucciones que permiten que la computadora funcione.

🪟 Sistema operativo

Es el programa principal que administra la computadora. Ejemplos: Windows y Linux.

🌐 Navegadores

Permiten entrar a páginas de Internet. Ejemplos: Chrome, Firefox y Edge.

📝 Procesadores de texto

Sirven para crear documentos. Ejemplo: Microsoft Word.

📊 Hojas de cálculo

Permiten organizar números y realizar operaciones. Ejemplo: Excel.

🛡️ Antivirus

Ayuda a detectar, bloquear y eliminar programas maliciosos.
